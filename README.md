# BilhetePass

Plataforma que conecta **donos de espaços**, **produtores de eventos** e **participantes**:
o dono oferece o local, o produtor aluga e publica o evento, o participante compra o
ingresso e entra — e, no fim, todo mundo se avalia e o dinheiro é repassado.

Projeto da disciplina **Requisitos, Projeto de Software e Validação** — CESAR School, 2026.2
